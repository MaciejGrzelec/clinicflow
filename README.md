# ClinicFlow

ClinicFlow is a microservices-based clinic management system built with Java, Spring Boot and React.

## Services

- api-gateway
- patient-service
- clinic-service
- appointment-service
- payment-service
- notification-service

## Technologies

- Java 21
- Spring Boot
- Spring Cloud Gateway
- Spring Security
- PostgreSQL
- MongoDB
- Apache Kafka
- Maven
- Docker
- React

## Planned features

- patient registration
- clinic and doctor management
- appointment scheduling
- online payments
- email notifications
- SMS notifications
- QR code check-in
- PDF, DOCX and XLSX generation
